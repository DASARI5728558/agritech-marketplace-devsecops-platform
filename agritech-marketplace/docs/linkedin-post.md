🚀 Built an AgriTech Marketplace on a complete Cloud-Native DevSecOps pipeline!

I created an end-to-end portfolio project — farmers list produce, buyers browse and order it — that demonstrates how modern applications are built, secured, deployed, and monitored in real-world DevOps environments.

🔧 Architecture Highlights:

✅ Infrastructure as Code with Terraform  
✅ CI/CD using GitHub Actions  
✅ Code quality scanning with SonarQube  
✅ Docker image vulnerability scanning with Trivy  
✅ Container registry using Amazon ECR  
✅ Kubernetes deployment on Amazon EKS  
✅ Helm-based application releases  
✅ Spring Boot application behind Nginx reverse proxy  
✅ Amazon RDS MySQL database  
✅ Observability using Prometheus and Grafana  
✅ Kubernetes ConfigMaps, Secrets, Services, Ingress, and Deployments

CI/CD Flow:

Developer → GitHub → GitHub Actions → SonarQube → Maven Tests → Terraform Apply → Docker Build → Trivy Scan → Amazon ECR → Helm Upgrade → Amazon EKS

Monitoring Flow:

Spring Boot Actuator + Kubernetes Metrics + Node Exporter → Prometheus → Grafana Dashboards

This project helped me practice the complete DevSecOps lifecycle:

- Source Control
- Infrastructure Provisioning
- Secure CI/CD
- Containerization
- Kubernetes Deployment
- Cloud Database Integration
- Monitoring and Observability

Tech Stack:

Terraform | AWS VPC | IAM | Amazon EKS | Amazon ECR | Amazon RDS | GitHub Actions | Docker | Helm | SonarQube | Trivy | Prometheus | Grafana | Nginx | Spring Boot | MySQL | Kubernetes
